# Expense Tracker

Application de suivi des dépenses en microservices, conteneurisée avec Docker et déployée sur Kubernetes.

## Architecture

- **frontend** : interface web (Nginx + HTML/JS)
- **expenses-service** : API de gestion des dépenses (FastAPI)
- **stats-service** : API de statistiques (FastAPI)
- **PostgreSQL** : base de données
